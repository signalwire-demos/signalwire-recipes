# Governed AI intake agent

> An intake agent that cannot skip a step, cannot see fields it should not, and cannot transfer before it has what it needs.

## What this demonstrates

Five governance recipes composed into one agent, so you can see how the constraints interact: scoped tools, a hidden data layer, handler-forced transitions, and a verification gate.

## How it works

Each composed recipe is documented on its own page; this build shows them running
in the same flow, with the state that has to survive between them.

## Limitations

A full application rather than a snippet. Read the composed recipes first if you
only need one piece.

## What to change first

The routing rules, then the copy.
