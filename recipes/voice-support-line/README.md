# Inbound support line

> A full inbound support number: menu, priority queue, hold, callback instead of waiting, and a recording of every call.

## What this demonstrates

Six recipes wired together into one number. The queue, the hold experience, the callback and the recording are separate ideas that only make sense once a caller is actually waiting.

## How it works

Each composed recipe is documented on its own page; this build shows them running
in the same flow, with the state that has to survive between them.

## Limitations

A full application rather than a snippet. Read the composed recipes first if you
only need one piece.

## What to change first

The routing rules, then the copy.
