# SMS Support Desk

> Inbound texts routed to the right queue, answered by the same agent logic as the phone line, with delivery handled properly.

## What this demonstrates

The same agent definition answering over text as over voice, with delivery status treated as the source of truth rather than the API response.

## How it works

Each composed recipe is documented on its own page; this build shows them running
in the same flow, with the state that has to survive between them.

## Limitations

A full application rather than a snippet. Read the composed recipes first if you
only need one piece.

## What to change first

The routing rules, then the copy.
